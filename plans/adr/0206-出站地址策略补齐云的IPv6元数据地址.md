# ADR-0206 出站地址策略补齐云的 IPv6 元数据地址

## 状态

已采纳（RFC-0008「出站地址策略」第 3 条修订）。

## 日期

2026-11-12

## 背景

5.0 安全审查 S-25（`plans/5.0-安全审查.md`），低危，这里复现确认。

- 出站地址策略在开了私网（`AllowPrivateNetwork`）之后仍拒绝 AWS 的 IPv6 元数据地址 `fd00:ec2::254`：它在 `fc00::/7` 里，开私网不等于开元数据。
- GCP（`fd20:ce::254`）与 Oracle（`fd00:c1::a9fe:a9fe`）的 IPv6 元数据服务同样在 `fc00::/7` 里，却没有列出。开了私网的宿主在这两家云上能被引去取实例凭据。

复现：`OutboundAddressPolicyTests.AllowPrivateNetwork_LeavesLoopbackAndMetadataDenied`。修正前，这两个地址在开了私网时被放行。

## 决策

- 私网段里的元数据地址列表：AWS `fd00:ec2::254`、GCP `fd20:ce::254`、Oracle `fd00:c1::a9fe:a9fe`，开了私网也拒绝，只能显式写进 `AllowedNetworks`。
- 其他云的元数据地址在链路本地（`169.254.0.0/16`）或运营商级 NAT（`100.64.0.0/10`）段，本来就不属于私网，照旧拒绝。

## 影响

- 确实要从这两家云的实例里访问元数据服务的出站客户端，要把地址写进 `AllowedNetworks`。
- 公开 API 不变。
