# ADR-0145 缺失用 null 不用空字符串

## 状态

已采纳（规范 `rfcs/0001-primitives.md`「稳定性级别」、`rfcs/0005-persistence.md`、`rfcs/0008-security.md` 修订）。

## 日期

2026-11-11

## 背景

API 审查指出，几个 `Stable` 契约用空字符串表示「没有」：

- 匿名主体的 `Principal.Id` 是空字符串，`IsAuthenticated` 靠「方案不为空且 ID 非空」推出。调用方只能写 `Id.Length == 0` 这类判断；也能构造出「有 ID 却未认证」「已认证却 ID 为空」的主体。
- `ResourceName.Tenant` 用空字符串表示全局资源。资源名的公开构造又不校验，能构造出解析不回去的值。
- `IMultiTenant.TenantId`、`IHasConcurrencyStamp.ConcurrencyStamp` 是不可空的 `string`，每个实体都要写 `= string.Empty`。

所有下游实体与认证处理器都依赖这些类型，GA 之后再改可空性就是破坏，所以规则要现在写定。框架其他地方已经用 `null` 表示缺失：审计的 `PrincipalId`、工作单元与授予存储的 `tenantId`、`TenantContext` 本身。

## 决策

- **规则写进 RFC-0001**：公开契约里可选的值缺失时用 `null`，不用空字符串或默认实例。
- **例外**：持久化写入的协议字段（`TenantId`、`ConcurrencyStamp`）类型不可空。
  - 已持久化的行一定有值：没有当前租户时新增被拒绝，并发戳在新增时生成。
  - 改成可空会让每个读已持久化实体的调用方都去处理一个不会出现的 `null`。
  - 新建实体在新增前以空字符串占位，新增时由持久化覆写；接口文档与 RFC-0005 写明这一点。
- **存储格式可以另行编码，在契约边界换算**。例如授予表以空字符串表示全局租户（唯一索引对 NULL 的语义各库不一致），契约 `PermissionGrant` 仍以 `null` 表示全局。
- **`Principal`**：
  - 改为显式构造 `Principal(id, authenticationScheme)`，两者都不得为空白，只用来创建已认证的主体。
  - 匿名主体只有 `Principal.Anonymous`，`Id` 与 `AuthenticationScheme` 都是 `null`。要带声明的匿名主体用 `Principal.Anonymous with { Claims = … }`。
  - `IsAuthenticated` 标注 `[MemberNotNullWhen(true, nameof(Id), nameof(AuthenticationScheme))]`，判断之后直接用 `Id`，不需要 `!`。
  - 不再是位置记录（ADR-0142）。
- **`ResourceName`**：
  - `Tenant` 改为 `string?`，全局资源为 `null`，文本形式仍是空段。
  - 构造与初始化器（含 `with`）按 `xrn` 文法校验每一段，传空字符串作租户被拒绝。
  - 它是封闭小值，保留位置形式。
- **框架内调用点**：
  - 幂等作用域键用 `Id ?? "-"`。
  - 权限检查在已认证分支里取 ID。
  - ASP.NET Core 认证桥收到匿名主体时按匿名处理，不生成身份。

## 影响

- 源码迁移：
  - `principal.Id.Length == 0` → `principal.Id is null` 或 `!principal.IsAuthenticated`。
  - `new Principal(id, null)` 不再可用：匿名就是 `Principal.Anonymous`。
  - 读 `Principal.Id` 的地方处理 `null`，或先判断 `IsAuthenticated`。
  - `new ResourceName(p, s, "", t, id)` → `new ResourceName(p, s, null, t, id)`；读 `Tenant` 时 `null` 表示全局。
- JSON 里匿名主体的 ID 由 `""` 变为 `null`，示例 `whoami` 的响应随之改变。
- 实体照旧写 `public string TenantId { get; set; } = string.Empty;`，不受影响。
- 这些类型都是 `Stable`，GA 前修改，不需要登记豁免（ADR-0131）。
