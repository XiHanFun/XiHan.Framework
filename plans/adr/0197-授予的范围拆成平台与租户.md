# ADR-0197 授予的范围拆成平台与租户

## 状态

已采纳（RFC-0008「RBAC 授予」修订）。

## 日期

2026-11-12

## 背景

5.0 安全审查 S-10（`plans/5.0-安全审查.md`），中危，这里复现确认。

- 授予是（主体，权限码，租户?），租户为空的授予对任何租户生效。
- 主体不带租户：`role:admin` 在平台和每个租户里是同一个主体，`user:42` 也一样。
- 平台把 `*` 授给 `role:admin`，某个租户管理员的令牌里也有 `role=admin`，他在自己的租户里就持有 `*`：平台为运营人员设的权限落到了每个租户里带同名角色的人身上。
- 分库后各租户的用户 ID 自增重复，平台给 `user:42` 的授予同样落到每个租户的 42 号用户身上。
- 「只给平台」与「给每个租户」是两种需求，原先只能表达成同一种。

复现：
- 一致性套件 `PermissionGrantStoreConformance` 与 `PermissionGrantAdministrationConformance` 改用显式范围后，两个实现都不合格。
- `DatabaseSecurityTests`：修正前平台授给 `role:editor` 的权限对 `acme` 里的 editor 同样放行。

## 备选

1. **操作契约声明「只限平台」，有租户的调用由 Authorize 拒绝**：否决。
   - 只挡住平台操作。平台授予照样落到租户里，租户管理员在自己的租户里拿到平台为运营人员设的全部权限。
   - 每个平台操作都要记得声明，漏一个就是越权。
2. **主体带租户（`role:acme:admin`）**：否决。令牌里的角色声明、授予表与全部授予来源都要改，租户专属授予已经能表达「这个租户的 admin」。
3. **授予的范围拆成平台、每个租户与租户专属**：采纳。

## 决策

1. **三种范围**，仍放在 `PermissionGrant.TenantId`：
   - `null`：平台授予，只对不带租户的调用生效。
   - `PermissionGrant.AnyTenant`（`*`）：每个租户的授予，对带任何租户的调用生效，对不带租户的调用不生效。`*` 不合租户 ID 文法（ADR-0196），不会与租户撞名。
   - 租户 ID：只对该租户生效。
   - 空白范围在构造 `PermissionGrant` 时抛出 `ArgumentException`。
2. **一次调用看得到的范围**：`PermissionGrant.VisibleScopes(tenantId)`。
   - 不带租户（`null` 或空）：只有平台。
   - 带租户：每个租户与该租户。
   - 调用的租户是 `*` 时抛出 `ArgumentException`。
   - 两个存储与测试夹具都按它取有效授予，平台与租户两边的授予互不渗透。
3. **不改形状**：
   - 两参数构造仍在，构造的是平台授予，是三种范围里最窄的。
   - 原先依赖「全局」在租户里生效的代码在租户调用里得到 403，不会悄悄多拿权限。
4. **管理与存储**：
   - `GrantTenantFilter.Global` 改名 `Platform`；`Of("*")` 列出每个租户的授予。
   - 列出顺序：平台在前、每个租户其次，然后按租户 ID。
   - 数据库的租户列：平台存空字符串（`PermissionGrantRecord.GlobalTenantId` 改名 `PlatformTenantId`），每个租户存 `*`。
   - 撤销不存在的平台授予用新消息键 `security.grant.platform_not_found`，参数 `subject`、`permission`，10 种语言。
5. **内存配置**：
   - `XiHan:Security:InMemory:Grants:<role|user>:<id>` 是平台授予。
   - 新增 `XiHan:Security:InMemory:AnyTenantGrants:<role|user>:<id>`，是每个租户的授予。

## 影响

- 破坏性变更：没有租户的授予不再对租户调用生效。
- 迁移：
  - 数据库：要对每个租户生效的旧全局授予，把租户列从空字符串改成 `*`。只给平台运营人员的授予保持空字符串。
  - 内存配置：租户里的用户要用的授予从 `Grants` 移到 `AnyTenantGrants`。
  - 代码：`new PermissionGrant(subject, permission)` 现在是平台授予，要对每个租户生效的写 `new PermissionGrant(subject, permission, PermissionGrant.AnyTenant)`。
  - `GrantTenantFilter.Global` 改为 `GrantTenantFilter.Platform`，`PermissionGrantRecord.GlobalTenantId` 改为 `PlatformTenantId`。
- 平台的人要在租户里持有权限，要另有一条每个租户或该租户的授予：平台身份不再自动带进租户。
- 示例 SimpleApp 的 `editor` 与 `viewer` 改到 `AnyTenantGrants`，`event-relay` 留在平台授予。
