# ADR-0153 查找方法按返回形状命名

## 状态

已采纳（规则见 `rfcs/0001-primitives.md`「稳定性级别」的「查找的命名」）。

## 日期

2026-11-11

## 背景

API 审查 R6 指出：同样是「可能没有」的查找，名字与返回形状对不上。

- `FeatureContext.TryGetBinding` 返回 `Maybe`，而 `TryGet` 在 BCL 里是 `bool` 加 `out`（框架自己的 `InvocationContext.TryGetBaggage` 也是）。
- 读调用上下文条目的扩展方法都叫 `Get…` 却返回 `Maybe`，如 `GetOutcome`、`GetOperation`、`GetCredential`、`GetTenantShard`，以及按键读条目的 `Get<T>(ContextItemKey<T>)`。
- 插件宿主的 `Describe(manifestId)` 返回可空的状态。
- `WorkflowVariables.Get(name)` 与 `Get<T>(name)` 返回 `null` 或默认值，分不清没有、JSON null 与转换失败。
- `GetAuditDetails` 没有时返回 `null`，有时交出内部可变字典。
- 框架里已有 46 个返回 `Maybe` 的 `Find…`（仓储、注册表、存储），是多数写法。

## 决策

1. **规则**：
   - `Find…` 返回 `Maybe<T>`（可失败或异步时包在 `Result` 与任务里）。
   - `TryGet…` 只用于 `bool` 加 `out`。
   - `Get…` 必定交出值，没有时是失败结果或编程错误。
   - 例外一：缓存条目的 `GetAsync` / `GetManyAsync` 沿用键值存储的词汇返回 `Maybe`，与批量优先的命名表一致。
   - 例外二：实现 BCL 或第三方接口的成员照原接口命名，如 `IDistributedCache.Get`。
2. **改名**：
   - `TryGetBinding` → `FindBinding`。
   - 调用上下文条目：`GetOutcome`、`GetOrigin`、`GetOperation`、`GetOperationPayload`、`GetOperationRequest`、`GetOperationResponse`、`GetCredential`、`GetAuthorizationRequirement`、`GetTenantShard`、`GetAuditAction`、`GetAuditResource` 改为对应的 `Find…`。
   - `MessageDispatcher.GetDelivery`、`JobDispatcher.GetRun`、`HttpContext.GetXiHanContext` 改为对应的 `Find…`。
   - `InvocationContext.Get<T>(ContextItemKey<T>)` 改为 `Find<T>`。
   - 必定有值的 `GetSecurity` 不变。
3. **插件宿主**：`OutOfProcessPluginHost.Describe` 与 `WasmPluginHost.Describe` 改为 `FindStatus(manifestId)`，返回 `Maybe<…Status>`。
4. **工作流变量**：删掉 `Get(name)` 与 `Get<T>(name)`。
   - 取原始值用索引器，没有或值为 JSON null 时为 `null`，两者用 `Contains` 区分。
   - 取类型化的值用 `TryGet<T>`。
5. **审计细节**：`GetAuditDetails` 改为 `FindAuditDetails`，返回此刻的只读副本，之后追加的细节不会改到已交出的字典。
6. **门禁**：架构测试 `LookupNamingTests` 检查两点，例外按决策 1：
   - `TryGet…` 返回 `bool` 且带 `out` 参数。
   - `Get…` 不返回 `Maybe`、可空引用。

## 影响

- 源码迁移只是改名：
  - `context.GetOutcome()` → `context.FindOutcome()`。
  - `context.Get(key)` → `context.Find(key)`。
  - `features.TryGetBinding(name)` → `features.FindBinding(name)`。
  - `host.Describe(id)` → `host.FindStatus(id)`，原来判 `null` 的写法改成 `TryGetValue`。
  - `variables.Get<T>(name)` → `variables.TryGet<T>(name, out var value)`。
- `Kernel` 的改名项是 `Stable`，其余是 `Preview`；GA 前修改，不需要登记豁免（ADR-0131）。
- 审计细节值的类型随存储不同（内存实现保留原对象，数据库读回 `JsonElement`）不在本 ADR，见第 6 批的审计项。
