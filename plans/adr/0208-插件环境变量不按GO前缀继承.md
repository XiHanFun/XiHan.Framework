# ADR-0208 插件环境变量不按 GO 前缀继承

## 状态

已采纳（`spec/plugin/handshake.md` §1 一条修订；Go 运行器同步）。

## 日期

2026-11-12

## 背景

5.0 安全审查 S-38（`plans/5.0-安全审查.md`），低危，这里复现确认。

- 宿主启动进程外插件时只继承白名单环境变量：名字白名单，加上前缀 `DOTNET_` 与 `GO`。
- 前缀 `GO` 本意是 Go 运行时的变量，但它同样放行了 `GOOGLE_APPLICATION_CREDENTIALS`、`GOOGLE_CLOUD_PROJECT` 等 Google 云的凭据与配置，零权限的插件也能拿到宿主的云凭据。

复现：`PluginEnvironmentTests.OnlyListedVariables_AreInherited`。修正前 `GOOGLE_*` 与 `GOPATH` 都被继承。

## 决策

1. Go 只继承运行时的调优变量：`GOMAXPROCS`、`GOGC`、`GOMEMLIMIT`、`GODEBUG`、`GOTRACEBACK`，按名字列出，不再按前缀。构建期的 `GOPATH`、`GOROOT`、`GOCACHE`，编译好的插件用不到。
2. `DOTNET_` 前缀保留：它是 .NET 运行时的配置，不放凭据。
3. Go 运行器 `xihan-conformance` 以宿主身份启动插件，同一规则。

## 影响

- 依赖宿主传下其他 `GO*` 变量的插件，要由运营方经插件的配置节或绑定显式交给它。
- 公开 API 不变。
