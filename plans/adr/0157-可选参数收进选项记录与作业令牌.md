# ADR-0157 可选参数收进选项记录，作业与领导租约的令牌对齐

## 状态

已采纳（规则见 `rfcs/0001-primitives.md`「稳定性级别」的「可选参数」与 RFC-0013）。

## 日期

2026-11-11

## 背景

API 审查第三节指出：

- **可选参数过多**：
  - `App.CreateContext(scopedServices, cancellationToken, traceId = null, spanId = null, deadline = null, baggage = null, traceFlags = null)` 是 `Stable`，有五个可选参数，令牌不在末位。可选参数的默认值编译进调用方，以后加一个参数就破坏二进制兼容；调用方还要靠命名实参跳着传。
  - `DomainEventBuffer(int capacity = 256)` 同理，`DefaultCapacity` 改了，已编译的调用方仍是 256。
  - 它交出的 `Items` 是内部的 `List`。
  - `TestHost.StartAsync`、`InvokeOperationAsync`、`TestManifests.Create` 也有一串可选参数。
- **作业的令牌重复**：`IJob.RunAsync(run, context, cancellationToken)` 的令牌与 `context.CancellationToken` 是同一个，派发器传的就是后者。实现可能只看其中一个，与操作的处理器 `HandleAsync(request, context)` 也不一致。
- **租约释放不对齐**：`LeaderLease.ReleaseAsync()` 不收令牌、不返回结果，同类型的 `RenewAsync(cancellationToken)` 返回 `Result`。后端释放失败时调用方无从得知。

## 决策

1. **规则**：公开方法不用一串可选参数。
   - 只有一个可选值时用重载。
   - 多个可选值时收进单次调用的选项记录，以后加字段只加属性。
   - `CancellationToken` 放最后。
   - 面向源码使用的工具链包（`Testing`、`Conformance`）例外，可选参数保留，新参数只加在末尾。测试项目总是随框架重新编译，二进制兼容对它们不成立。
2. **`App.CreateContext`**：
   - 改为 `CreateContext(scopedServices, cancellationToken)` 与 `CreateContext(scopedServices, InvocationContextOptions options, cancellationToken)` 两个重载。
   - 新增 `Stable` 的 `InvocationContextOptions`：`TraceId`、`SpanId`、`TraceFlags`、`Deadline`、`Baggage`，都可省略，`None` 是空选项。语义不变。
3. **`DomainEventBuffer`**：
   - 改为 `DomainEventBuffer()`（`DefaultCapacity`）与 `DomainEventBuffer(int capacity)`。
   - `Items` 交出只读视图。
4. **`IJob.RunAsync(run, context)`**：去掉令牌参数，取消与超时一律看 `context.CancellationToken`。
5. **`LeaderLease.ReleaseAsync(cancellationToken)`**：
   - 返回 `ValueTask<Result>`。
   - 幂等，已释放或已失去时直接成功；后端没能删掉租约时返回那个失败，租约到期后自然可被接管。
   - `DisposeAsync` 以 `CancellationToken.None` 释放并忽略结果。
   - 一致性套件断言释放与重复释放都成功。
6. **测试宿主不改**：`TestHost` 与 `TestManifests` 按规则 1 的例外保留可选参数。

## 影响

- 源码迁移：
  - `App.CreateContext(sp, ct, deadline: d, baggage: b)` → `App.CreateContext(sp, new InvocationContextOptions { Deadline = d, Baggage = b }, ct)`；只传服务与令牌的调用不用改。
  - 实现 `IJob` 的类删掉第三个参数，方法里的 `cancellationToken` 改为 `context.CancellationToken`。
  - `await lease.ReleaseAsync()` → `await lease.ReleaseAsync(cancellationToken)`，需要时读返回的 `Result`；实现 `LeaderLease` 的 Provider 改签名。
  - `new DomainEventBuffer(capacity: n)` 照常编译。
- `App`、`InvocationContextOptions`、`DomainEventBuffer` 是 `Stable`，`IJob`、`LeaderLease` 是 `Preview`；GA 前修改，不需要登记豁免（ADR-0131）。
