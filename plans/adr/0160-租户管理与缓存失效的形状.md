# ADR-0160 租户管理的可选接口，缓存失效改为批量加全部

## 状态

已采纳（RFC-0007、RFC-0022）。

## 日期

2026-11-11

## 背景

API 审查第三节指出：

- **租户写入没有统一契约**：
  - `MultiTenancy.InMemory` 是单条、同步的 `Set(tenant)` / `Remove(tenantId)`，删除不存在返回 `false`。写入后不失效分片解析器的缓存，改了租户连接还会落到旧库。
  - `MultiTenancy.Database` 的 `TenantRecordStore` 是批量异步、逐项结果，写后失效缓存。它另有一个 `ListAsync(skip, take)`，与 `ITenantStore.ListAsync(TenantQuery)` 重复。
- **缓存失效以 `null` 表示全部，也没有批量形式**：
  - `ITenantShardResolver.Invalidate(string? tenantId = null)` 与 AI 的 `IAIProviderCatalog.Invalidate(string? name = null)` 都是这样，数据库租户目录与授予缓存的公开 `Invalidate` 同型。
  - 一次写入多个租户只能逐个失效，违背批量优先第 1 条。
  - 漏传参数就清空全部缓存，与全组「`null` 表示全局 / 缺失」的规则冲突（RFC-0001）。

## 决策

1. **新增可选接口 `ITenantAdministration`**（`MultiTenancy.Abstractions`，`Preview`）：
   - `UpsertAsync(tenants[])`：整份覆盖，同一批里后一项覆盖前一项，新增超出容量为 `MULTITENANCY_UNAVAILABLE_001`。
   - `RemoveAsync(tenantIds[])`：不存在为 `MULTITENANCY_NOTFOUND_001`，同一批里第二次同样不存在。
   - 逐项结果与入参同序，空集合不访问后端。写入后让租户目录与分片解析器丢弃这些租户的缓存。
   - 列出只经 `ITenantStore.ListAsync`。
2. **两个实现**：
   - 内存实现：`InMemoryTenantStore` 的 `Set` / `Remove` 不再公开，改为一次加锁处理整批的内部方法。由内部类型 `InMemoryTenantAdministration` 实现接口并失效分片缓存。
     - 不由存储自己实现，是因为分片解析器读存储，存储再依赖解析器会成环。
   - 数据库实现：`TenantRecordStore` 实现接口，删掉重复的 `ListAsync(skip, take)`。
   - 两个特性都把它登记为 `ITenantAdministration`：内存是单例，数据库是作用域服务。
3. **缓存失效的形状**：`Invalidate(ids[])` 加显式的 `InvalidateAll()`，空集合什么也不做，不以 `null` 表示全部。涉及：
   - `ITenantShardResolver` 与 `TenantStoreShardResolver`。
   - `DatabaseTenantStore`。
   - `DatabasePermissionGrantStore`（按主体）。
   - `IAIProviderCatalog` 与 `AIProviderCatalog`：`Dispose` 调 `InvalidateAll`，释放放在锁外。
4. **一致性套件 `TenantAdministrationConformance`**：
   - 写入同序，后一项胜出，目录随即看见。
   - 整份覆盖清掉没给的字段。
   - 删除逐项报告不存在，空集合返回空。

## 影响

- 源码迁移：
  - `store.Set(tenant)` → `await tenants.UpsertAsync([tenant], ct)`，读 `[0]`。
  - `store.Remove(id)` 的 `bool` → `await tenants.RemoveAsync([id], ct)` 的 `Result`，不存在是 `MULTITENANCY_NOTFOUND_001`。
  - 管理代码注入 `ITenantAdministration`，内存实现写后不必再手动失效分片缓存。
  - `TenantRecordStore.ListAsync(skip, take)` → `ITenantStore.ListAsync(new TenantQuery { PageSize = … }, ct)`，按续页令牌翻页。
  - `resolver.Invalidate("acme")` → `resolver.Invalidate(["acme"])`，`resolver.Invalidate()` → `resolver.InvalidateAll()`。AI 目录、数据库租户目录与授予缓存同样改。
  - 实现 `ITenantShardResolver` 或 `IAIProviderCatalog` 的 Provider 补上两个方法。
- 改动的类型都是 `Preview`；GA 前修改，不需要登记豁免（ADR-0131）。
