# ADR-0158 授予管理的可选接口

## 状态

已采纳（RFC-0008「RBAC 授予」）。

## 日期

2026-11-11

## 背景

API 审查第三节指出，授予的写入没有统一的抽象：

- `Security.InMemory` 是单条、同步的 `Grant(grant)` / `Revoke(grant)`。撤销不存在的授予返回 `false`，容量用尽返回 `Result`。
- `Security.Database` 的 `PermissionGrantRecordStore` 是批量、异步的 `GrantAsync` / `RevokeAsync`，撤销不存在的返回 `SECURITY_NOTFOUND_002`。
- 列出只有数据库实现有：`ListAsync(subject?, tenantId?, skip, take)`。
  - `tenantId` 为 `null` 表示「不按租户过滤」，与全组「`null` 表示全局」冲突，也就无法只列全局授予。
  - `take` 超限时抛出异常，不报总数，返回 `Task` 与实体行。
- 应用的管理界面要按实现分别写代码，换 Provider 就要改。

## 决策

1. **新增可选接口 `IPermissionGrantAdministration`**（`Security.Abstractions`，`Preview`）：
   - `GrantAsync(grants[])` / `RevokeAsync(grants[])`：逐项结果与入参同序。已存在的授予幂等成功，容量用尽是 `SECURITY_UNAVAILABLE_002`，撤销不存在的是 `SECURITY_NOTFOUND_002`，同一批里后一项看见前一项的效果。空集合返回空列表，空白租户是编程错误。
   - `ListAsync(PermissionGrantQuery)`：
     - 返回 `PermissionGrantPage`（`Items`、`long Total`）。
     - 顺序是主体种类、主体 ID、权限码、租户（全局在前）。
     - 单条写法是扩展方法 `GrantAsync(grant)` / `RevokeAsync(grant)`。
   - 与只读的 `IPermissionGrantStore` 分开：只供判定的存储不必实现管理。
2. **查询**：
   - `PermissionGrantQuery` 按 R7 的偏移分页（`Skip`、`Take`，`MaxTake` 1000，缺省 100）。
   - 越界不在构造时抛出，由 `ListAsync` 经 `Validate()` 返回新错误码 `SECURITY_VALIDATION_005`（消息键 `security.grant.query_page_invalid`，参数 `skip`、`take`、`max`）。
3. **租户过滤是显式的 `GrantTenantFilter`**：
   - `Any` 不过滤，是缺省；`Global` 只要全局；`Of(tenantId)` 只要该租户的专属授予。
   - 不再用 `null` 表示「不过滤」。
4. **两个实现都实现它**：
   - `InMemoryPermissionGrantStore` 的同步 `Grant` / `Revoke` 不再公开。批量方法各一次加锁处理整批（批量优先第 2 条），在锁外排序分页。
   - `PermissionGrantRecordStore` 的旧 `ListAsync(subject, tenantId, skip, take)` 删除，改为按查询在数据库里过滤、计数与分页，返回契约的 `PermissionGrant`。
   - 两个特性都把它登记为 `IPermissionGrantAdministration`：内存是单例，数据库是作用域服务。
5. **一致性套件 `PermissionGrantAdministrationConformance`**：
   - 授予同序幂等并对判定可见。
   - 撤销逐项报告不存在。
   - 按主体、全局、指定租户过滤，分页与总数。
   - 越界返回校验错误。

## 影响

- 源码迁移：
  - `InMemoryPermissionGrantStore.Grant(grant)` → `await grants.GrantAsync(grant, ct)`。
  - `Revoke(grant)` 的 `bool` → `await grants.RevokeAsync(grant, ct)` 的 `Result`，不存在是 `SECURITY_NOTFOUND_002`。
  - 管理代码注入 `IPermissionGrantAdministration`，不再依赖具体实现。
  - `PermissionGrantRecordStore.ListAsync(subject, tenantId, skip, take)` → `ListAsync(new PermissionGrantQuery { Subject = …, Tenant = GrantTenantFilter.Of(…), Skip = …, Take = … }, ct)`，读 `Items` 与 `Total`。原来传 `tenantId: null` 表示不过滤的，改为缺省的 `Any`。
- 新增类型与错误码都是 `Preview`；GA 前修改，不需要登记豁免（ADR-0131）。
