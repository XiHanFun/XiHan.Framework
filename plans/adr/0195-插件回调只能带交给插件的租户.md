# ADR-0195 插件回调只能带交给插件的租户

## 状态

已采纳（`spec/plugin/invocation.md` §2、§5，`spec/plugin/wasm.md` §4 与中间件一节，`spec/plugin/plugin.proto` 一处注释；RFC-0017、RFC-0018 各一条修订）。

## 日期

2026-11-12

## 背景

5.0 安全审查 S-30（`plans/5.0-安全审查.md`），中危，这里复现确认。

- 回调以插件身份执行：主体 ID 是清单 ID，没有声明。元数据里的 `xihan.tenant` 原样进入回调上下文，Tenant 阶段的声明解析器拿不出租户，Baggage 解析器就采用插件自报的租户，只核对它存在且启用。
- 插件因此能在任何启用的租户里调用宿主操作：外层调用属于 acme，回调写 globex，就在 globex 里执行，数据过滤、分片与审计都按 globex 处理。
- `Host.Publish` 的信封自带 `xihantenant` 扩展时，发布器保留它，订阅方在那个租户里处理。
- Wasm 中间件的 `CONTINUE` 能改写 `xihan.tenant`：Tenant 阶段之前的插件中间件能把任何调用放进任意启用的租户，匿名调用也一样。

复现：`WasmCallbackTenantTests`、`CallbackTenantTests`。修正前，回调与中间件指定的 globex 生效，信封带 globex 照样发布。

## 备选

1. **回调一律不带租户**：否决。插件处理某个租户的调用时，回调读写这个租户的数据是正当需求。
2. **回调租户由宿主强制成外层调用的租户，忽略插件写的值**：否决。进程外插件并发处理调用，回调不指明它属于哪次调用，宿主找不到「外层」；静默替换插件写的值也违背「不静默兜底」。
3. **回调只能带宿主交给插件处理的调用的租户，越界即拒绝**：采纳。

## 决策

1. **交给插件的租户**：宿主调用插件时，元数据里的 `xihan.tenant` 写这次调用的租户。
   - 安全上下文有租户时取它。
   - Tenant 阶段裁定为无租户时不带，不回退到调用方自报的 Baggage。
   - 还没有裁定（宿主没有 Tenant 阶段，或调用还没走到它）时，原样传递调用携带的值。
   - `PluginMetadata.TenantOf` 是这条规则的唯一实现，元数据与运行时共用。
2. **回调与发布**：
   - `Host.Invoke` / `xihan.invoke` 的元数据带 `xihan.tenant` 时，它必须是宿主此刻交给该插件处理的某个调用的租户，否则不执行，返回 `PLUGINS_DENIED_002`（消息键 `plugins.callback.tenant_denied`，参数 `id`、`tenant`）。
   - `Host.Publish` / `xihan.publish` 的信封带 `xihantenant` 时逐项按同一规则判定，越界的那一项被拒，其余照常发布。
   - 不带租户的回调是无租户调用，与以前相同。
   - 判定在权限判定之后、建作用域之前。
3. **「此刻交给插件处理的调用」**：
   - Wasm 调用串行，就是当前调用：`RunCall` 记下它的租户，再入沿用。没有当前调用（实例化期间的 `_initialize`）时不能带租户。
   - 进程外插件并发，取在途调用的租户集合：`PluginTenantCalls` 在操作调用与事件投递期间按租户计数，计数归零即移除，条目数不超过在途调用数。调用结束后的回调不能带租户。
4. **中间件**：Wasm 中间件的 `CONTINUE` 不能改写 `xihan.tenant`，与 `xihan.principal` 一样被丢弃。

## 影响

- 行为：
  - 原样转发收到的元数据的插件不受影响，回调落在调用的租户里。
  - 自己挑租户的插件被拒绝（`PLUGINS_DENIED_002`）；要跨租户执行的插件逻辑应改为宿主侧的平台操作，由宿主代码决定租户。
  - 依赖中间件改写租户的 Wasm 插件不再生效。租户应由 Tenant 阶段的解析器决定，应用要按请求选租户时自己实现 `ITenantResolver`。
- 进程外插件并发处理多个租户的调用时，回调可以带其中任何一个：宿主分不清回调属于哪次调用。这是剩余风险，比原先的「任意启用的租户」窄得多。
- Tenant 阶段之前的插件中间件拿到的是调用方自报、尚未裁定的租户，回调带它时由回调自己的 Tenant 阶段按插件身份校验。
- 公开 API：`PluginMessages.CallbackTenantDenied`，10 种语言的文案。
- 示例 EchoPlugin 的 `echoes.relay` 增加 `tenant`，用来在测试里伪造回调的租户。
