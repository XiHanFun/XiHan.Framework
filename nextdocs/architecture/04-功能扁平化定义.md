# XiHan Framework — 功能扁平化定义

> 版本：5.0.0-preview.1 | 状态：草案 | 最后更新：2026-10-21
>
> 本文从属于 [下一代框架总体方案](../下一代框架总体方案.md)；包名由总体方案 §5.3 文法与 §5.4 术语表推出。

---

## 零、设计原则

**每个功能独立声明，依赖通过能力图谱表达，不通过命名空间层级隐含从属。**

- 一个功能 = 一个 NuGet 包 + 一份 `xihan.manifest.json`。使用者按需引用，按需 `UseFeature<T>()`。
- 包名由"领域 + 角色"唯一推出；领域词只能取自术语表。
- 依赖按能力 ID 和版本范围声明，不按包名；同一能力可由多个 Provider 提供。
- 每个抽象必须有一个 `role: default` 的默认实现，包名按机制命名。

## 一、Ring 0 / 1：原语与内核（必须存在）

### F001 — 原语层

| 属性 | 值 |
| --- | --- |
| **包名** | `XiHan.Framework.Primitives` |
| **能力标识** | `primitives@1` |
| **稳定性** | Stable + 冻结 |
| **依赖** | 无（仅 `Microsoft.Extensions.*` 抽象包） |
| **职责** | 零行为的原语与契约，跨语言语义一致 |

**包含类型**：`Result<T>` / `Result`、`Error`、`Maybe<T>`、`TypedId<T>`、`InvocationContext` 契约、清单模型、`Stability` / `ApiLevelAttribute`、`LifecycleState`、`FrameworkException`、`FrameworkInfo`。

**不做**：不含任何实现、基类、时间抽象（用 `TimeProvider`）、ID 生成、实体契约、事件总线。

### F002 — 内核

| 属性 | 值 |
| --- | --- |
| **包名** | `XiHan.Framework.Kernel` |
| **能力标识** | `kernel.hosting@1`、`kernel.capabilities@1`、`kernel.pipeline@1`、`kernel.diagnostics@1`、`kernel.security@1`、`kernel.plugins@1` |
| **稳定性** | Stable（`Kernel.Plugins` 命名空间 Preview） |
| **依赖** | `primitives@^1` |
| **职责** | 宿主、能力图谱、执行管道、诊断薄桥、安全原语、插件宿主抽象 |

**命名空间与内容**：

| 命名空间 | 包含 |
| --- | --- |
| `Kernel.Hosting` | `AppBuilder`、`App`、`IFeature`、`IHostedFeature`、`FeatureContext`、`FeatureCollection`、Generic Host 集成、状态机、探针聚合、资源绑定 |
| `Kernel.Capabilities` | `[Capability]`、清单读取、能力图谱、版本约束求解、已解析图 |

| `Kernel.Diagnostics` | `ActivitySource` / `Meter` 桥、`IAuditSink`、`AuditEvent` |
| `Kernel.Security` | `IPrincipal`、租户上下文、资源名 `xrn:`、`IPolicy`、`AuthorizationResult`、权限定义注册表 |
| `Kernel.Plugins` | `IPlugin`、`IPluginHost`、`IPluginContext`、权限授予接口 |

**不做**：不处理 HTTP；不含任何子系统抽象；不含具体隔离机制的插件加载器。

### F003 — 内核分析器与生成器

| 包名 | 职责 |
| --- | --- |

### F004 — ASP.NET Core 宿主

| 属性 | 值 |
| --- | --- |
| **包名** | `XiHan.Framework.Hosting.AspNetCore` |
| **能力标识** | `hosting.aspnetcore@1` |
| **稳定性** | Stable |
| **依赖** | `kernel.hosting@^1` |
| **职责** | `AddXiHan()` / `UseXiHan()`，探针端点，优雅停机对齐，协议适配器挂载点 |

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.AddXiHan(xihan => xihan
    .UseFeature<SecurityFeature>()
    .UsePipeline(pipeline => pipeline
        .UseAt<TenantResolutionMiddleware>(PipelineStage.Tenant)
        .UseAt<AuthorizationMiddleware>(PipelineStage.Authorize)));

var app = builder.Build();
app.UseXiHan();
app.Run();
```
