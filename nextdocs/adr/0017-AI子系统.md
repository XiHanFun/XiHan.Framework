# ADR-0017 AI 子系统：以 Microsoft.Extensions.AI 为线格式，操作契约即工具

## 状态

已采纳（RFC-0022）。

## 日期

2026-10-26

## 背景

[06-BasicApp迁移清查](../architecture/06-BasicApp迁移清查.md) 把 `AI.*` 列为硬阻塞：BasicApp.AI（65 文件、6 051 行）依赖 4.x 的 `IXiHanAiService`、`IAiChatClientResolver`、`IAiSkill` 与 `Rag`。总体方案把 `AI.Abstractions`（`ai.chat@1`、`ai.embedding@1`、`ai.tools@1`）放在 5.x 后续、默认实现"无"。用户于 2026-10-25 拍板提前到现在做，范围：抽象 + OpenAI 兼容端点 + 知识库（`ai.knowledge@1`），并把操作契约桥接成模型工具。要决定模型接口用谁的、工具从哪来、知识库的存储边界、默认实现有没有。

## 备选

1. 自定义模型接口（`IAIModel`、`AIMessage`…），Provider 各自适配。
2. 直接用 `Microsoft.Extensions.AI` 的 `IChatClient` / `IEmbeddingGenerator` / `AITool` 作为公开契约，框架只做目录、护栏、提示词、工具与知识库。
3. 工具只允许显式登记（4.x 的 `IAiSkill`）。
4. `[Operation]` 契约加 `Expose.Ai`，登记表里的操作自动成为 `AIFunction`，经完整管道执行。
5. 知识库直接依赖某个向量库 SDK。
6. 知识库定义 `IKnowledgeStore` 契约，`AI.VectorData` 适配 `Microsoft.Extensions.VectorData` 的 `VectorStore`（由应用注册连接器）。

## 决策

- 取 2：`Microsoft.Extensions.AI.Abstractions` 与 `Microsoft.Extensions.VectorData.Abstractions` 是 Ring 2 允许的 `Microsoft.Extensions.*.Abstractions` 包，公开签名可以出现它们的类型；不复制一套模型接口。
- 取 4 并保留显式登记：`Expose.Ai = 16`（进 `All`），`IAIToolCatalog` 合并 `AddAITool(AITool)` 与 `Expose.Ai` 的操作；操作工具按调用方上下文绑定，在新作用域、新 `InvocationContext` 里经完整管道执行，Authorize 阶段按契约判定，失败以 JSON 错误对象交给模型，与 `Protocols.Mcp` 的 `tools/call` 同构。
- 取 6：`IKnowledgeStore` 只管记录的写入、按文档删除与向量搜索；切块、嵌入、检索与提示增强在 `AI.Abstractions` 里，与 Provider 无关。
- 默认实现：`ai.tools@1` 由 `AI.Abstractions` 的 `AIToolsFeature` 默认提供（进程内，零外部依赖，进 `Profiles.Full`）；`ai.chat` / `ai.embedding` / `ai.knowledge` 没有默认——模型端点与向量存储都是外部资源，框架不伪造。
- 护栏在 `IAIChat` 里按登记顺序执行，不做 `DelegatingChatClient`：直接从目录取 `IChatClient` 的调用方自己负责。
- 4.x 的 Agent 工厂不迁：`Microsoft.Agents.AI` 未稳定，另立 RFC。

## 理由

- 线格式用 M.E.AI 后，应用可以把任何 M.E.AI 中间件（缓存、遥测、函数调用）叠在目录解析出的客户端上，框架不用追模型 API 的变化。
- 操作即工具让"一份契约三种协议"扩展到模型：权限、审计、事务与多租户都走同一条管道，工具不会绕过授权。
- 存储契约与流水线分离，换向量库只换 `VectorStore` 连接器，一致性套件保证语义一致。

## 影响

- 新包：`AI.Abstractions`（Ring 2，含 `AIToolsFeature`）、`AI.OpenAI`（Ring 3，依赖 `Microsoft.Extensions.AI.OpenAI`）、`AI.VectorData`（Ring 3）、`AI.Conformance`；内核 `Expose.Ai`；插件握手 `expose` 接受 `ai`；新 RFC-0022；错误码 `AI_*`；消息目录 `ai`；`capability-ids` 登记 `ai.knowledge`。
- `Directory.Packages.props` 新增 `Microsoft.Extensions.AI.Abstractions`、`Microsoft.Extensions.VectorData.Abstractions`（抽象组）与 `Microsoft.Extensions.AI`、`Microsoft.Extensions.AI.OpenAI`、`Microsoft.Extensions.Http`（Provider 组）。
- `Expose.All` 的数值从 15 变为 31；`Kernel.Generators` 生成的数值随之变化。
- `xihan migrate v4` 的 AI 映射随 BasicApp.AI 模块迁移时补。
