# ADR-0006 进程外 gRPC 插件协议进 5.0，Wasm 标 Experimental

## 状态

已采纳

## 日期

2026-10-21

## 背景

插件轴要支持不可信代码与任意语言。三种隔离级别中，进程内最简单，Wasm 最新，进程外最通用。

## 备选

1. 5.0 只做进程内插件，其余后续。
2. 5.0 做进程内 + 进程外，Wasm 标 Experimental。

## 决策

采用备选 2。`Plugins.InProcess` 在 P1，`Plugins.OutOfProcess`（子进程 + gRPC `xihan.plugin.v1`）在 P4，`Plugins.Wasm` 在 P4 以 Experimental 发布。

## 理由

- 进程外协议同时是跨语言插件与远程 Provider 的基础，也是 Go SDK 的第一个真实用例。
- Wasm 组件模型与 wasmtime .NET 绑定仍在演进，不宜在 5.0 承诺稳定。

## 影响

- `spec/plugin/plugin.proto` 是 5.0 规范性内容。
- 插件清单的 `isolation`、`permissions`、`activation` 字段在 RFC-0002 中定义。
