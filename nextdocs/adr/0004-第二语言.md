# ADR-0004 第二语言 Go 先行

## 状态

已采纳

## 日期

2026-10-21

## 背景

同名框架要在多种语言可用，前提是 XiHan Spec 不是 .NET 形状的规范。第二语言的选择决定规范能否被真正检验。

## 备选

1. TypeScript 先行：对接 XiHan.UI 与 MCP 生态。
2. Go 先行：离 C# 最远，承载进程外插件宿主、k8s Operator 与一致性运行器。

## 决策

采用备选 2。P4 以 Go SDK 通过全部一致性向量、Go 插件在 .NET 宿主中服务一个操作为退出条件；TypeScript 其次。

## 理由

- Go 没有泛型约束链、没有属性注入、没有 Attribute，能逼出规范里隐含的 .NET 假设。
- 进程外插件协议、Operator、一致性运行器本身就适合用 Go 写。

## 影响

- `spec/plugin/plugin.proto` 必须在 P4 前定稿。
- Go 包路径 `github.com/xihanfun/xihan-go`。
