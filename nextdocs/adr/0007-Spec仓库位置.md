# ADR-0007 Spec 先留在 `next/spec/`，P4 公开时拆出

## 状态

已采纳

## 日期

2026-10-21

## 背景

规范与 .NET 参考实现在早期会频繁一起改；过早拆仓库会让每次契约调整跨两个仓库。

## 备选

1. 立即建立独立仓库 `XiHanFun/xihan-spec`。
2. P0–P3 留在 `next/spec/`，P4 公开时拆出并保留历史。

## 决策

采用备选 2。

## 理由

- 早期一个 PR 同时改规范、实现与向量，审查成本最低。
- 第二语言出现前，独立仓库没有第二个消费者。

## 影响

- `next/spec/` 的目录布局按未来独立仓库设计，拆出时用 `git subtree split` 保留历史。
- 规范文件的链接一律用相对路径。
