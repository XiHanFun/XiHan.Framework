# ADR-0002 `Primitives` 与 `Kernel` 分包，原语层单独冻结

## 状态

已采纳

## 日期

2026-10-21

## 背景

十年稳定的承诺只能落在极小的一层上。`Result`、`Error`、`Maybe`、`TypedId`、调用上下文契约、清单模型、稳定性标记需要跨语言一致且永不破坏；内核则会随小版本演进。

## 备选

1. 原语留在 `Kernel`，用 `[ApiLevel]` 标注冻结。
2. 原语独立为 `XiHan.Framework.Primitives`，与 `Kernel` 分开发布。

## 决策

采用备选 2。`Primitives` 零依赖、零行为，公开面以 `PublicAPI.Shipped.txt` 为准，只增不改；破坏即新包 `Primitives.V2` 并存。公开名字不带 `XiHan` 前缀：`Result<T>`、`Error`、`Maybe<T>`、`TypedId<TTag, TValue>`、`InvocationContext`、`FrameworkException`、`FrameworkInfo`、`Stability`、`ApiLevelAttribute`、`LifecycleState`。

## 理由

- 分包让"冻结"可以用包验证基线机械执行，而不是靠标注与人审。
- 其他语言 SDK 只需对齐原语层就能互通，内核形态可各自选择。
- Rust `core / std`、Linux 系统调用 ABI 的分层经验。

## 影响

- 架构测试强制 `Primitives` 没有任何项目引用与包引用。
- RFC-0001 定义公开面；P1 填充。
- `Kernel` 依赖 `Primitives` 与 `Microsoft.Extensions.*` 抽象包。
