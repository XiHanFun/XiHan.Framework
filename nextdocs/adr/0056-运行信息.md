# ADR-0056 运行信息

## 状态

已采纳（新增 `spec/rfcs/0023-observability.md`；术语表 `Observability` 的边界加上「进程与主机的运行信息」，能力 ID 表加 `observability.host`）。

## 日期

2026-10-30

## 背景

BasicApp 6.0 N2 第七批（Maintenance）做 4.x 的服务监控页时报告：5.0 没有 CPU、内存、磁盘、网卡、GPU、主板与运行时长的读取。4.x 框架在 `Utils/Diagnostics/HardwareInfos` 有六个 Helper（Cpu / Ram / Disk / Network / Gpu / Board），加上 `OsPlatformHelper` 的运行时信息，页面显示的就是这些。按「4.x 框架有、5.0 没有的在框架实现」，由框架提供，BasicApp 不写替代。

4.x 的取数靠外部命令：Windows 的 `powershell Get-CimInstance`，Linux 的 `dmidecode`、`lspci`、`nvidia-smi`、`top`、`df`，macOS 的 `system_profiler`、`sysctl`、`vm_stat`。外部命令可能挂起，命令行拼接有注入面，读一次 CPU 使用率还要睡眠采样。

## 决策

- 包与词汇：
  - 契约进新包 `Observability.Abstractions`（Ring 2）：`IHostMonitor` 与七份记录，以及从 `Observability.OpenTelemetry` 移过来的 `ObservabilityCapabilities`（新增 `Host`）。
  - 实现进新包 `Observability.Host`（Ring 3，`role: default`），提供 `observability.host@1`，`Profiles.Full` 装上它。
  - 术语表 `Observability` 的边界扩成「导出器与采样配置；进程与主机的运行信息」。
- 不启动外部命令：只读 BCL、`/proc` 与 `/sys`、`pci.ids`、注册表与 kernel32 的三个函数（`GetSystemTimes`、`GetLogicalProcessorInformation`、`K32GetPerformanceInfo`）。
- 读不到的项为 `null`，不以 0 或空串顶替；单项失败只让该项为空，读取不抛出。
- 使用率与速率由后台采样器求两次采样之差：
  - 启动时同步采一次，之后按 `XiHan:Observability:Host:SampleIntervalSeconds`（默认 5）采样。
  - 读取只返回最近算出的值，不睡眠、不等待；启动后第一个间隔内为空。
  - 计数变小或总增量为零时该项为空，百分比限制在 0–100。
- 平台：
  - Linux 与 Windows 读全部项，各自的路径写进 RFC-0023。
  - macOS 等只有 BCL 读得到的部分。
- 与 4.x 的差异写进 RFC-0023「与 4.x 的已知差异」，不静默缺失。主要是：
  - NVIDIA 专有驱动的显存与温度。
  - GPU 使用率、显示模式与设备状态。
  - Windows 的主板序列号与空闲内存。
  - macOS 的 CPU、内存、GPU 与主板。
  - 网卡的 DHCP 与错误计数。
  - 命令行参数与环境变量。

## 理由

- 不调外部命令：读取不会挂起、没有注入面，也不依赖目标机器装了哪些工具；代价是少数只有厂商工具或 WMI 才给的项，已列为已知差异。
- 采样放后台：服务监控页轮询时不阻塞请求线程，也不会因为并发请求各睡一次而放大开销。
- `null` 而不是 0：前端能区分「没有」与「为零」，例如没有温度传感器与 0℃。
- Linux 的读取路径以根目录为参数：夹具用例在任何系统上都能覆盖 `/proc` 与 `/sys` 的解析；CI 只有 Linux，Windows 的用例在本机运行。
- 能力 ID 常量移到抽象包：两个实现包共用一处定义；`ObservabilityCapabilities` 还在 Unshipped，移动不留兼容别名。

## 影响

- 公开 API：
  - 新包 `Observability.Abstractions`：`ObservabilityCapabilities`（`Export`、`Host`、`Version`）、`IHostMonitor`、`RuntimeInfo`、`ProcessorInfo`、`MemoryInfo`、`DiskInfo`、`NetworkInterfaceInfo`、`GpuInfo`、`BoardInfo`。
  - 新包 `Observability.Host`：`HostObservabilityFeature`、`HostObservabilityOptions`。
  - `Observability.OpenTelemetry`：`ObservabilityCapabilities` 移出，命名空间改为 `XiHan.Framework.Observability.Abstractions`。
- 行为：`Profiles.Full` 多一个后台采样循环，默认每 5 秒读一次 CPU 时间与网卡计数。
- 测试：
  - Linux 夹具：CPU 型号、核心、频率与缓存，CPU 时间，内存，运行时长，主板，显卡与 `pci.ids`，挂载表。
  - 采样器：首次为空、使用率与速率的换算、计数变小为空、限制在 100、后台循环。
  - 真实机器：Windows 与 Linux 各一例，只在对应系统上运行。
  - 宿主：取到 `IHostMonitor`，一个间隔后有 CPU 使用率；选项的解析与校验。
