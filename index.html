框架简介
为什么选择曦寒
  • 🧩

    模块化装配

    一个模块就是一个类，用 [DependsOn] 声明它依赖谁。框架启动时自动拓扑排序、依次加载，不用手写一长串 AddXxx，也不用操心注册顺序。

    了解模块系统

  • 🚀

    动态 API

    应用服务打上 [DynamicApi] 就是 REST 接口，动词与路由由方法名推导，不写 Controller、不写路由特性，Scalar 文档自动生成。

    了解动态 API

  • 📦

    按需引用

    各包按七层组织，用什么装什么。上层包会通过 [DependsOn] 自动带上它依赖的底层，大多数包无需单独安装。

    浏览模块总览

  • 🔐

    企业级能力齐备

    多租户、认证授权、工作单元与事务、缓存与分布式锁、事件总线、定时任务、工作流、审计、可观测性，按能力域分 38 章讲清楚。

    查看开发指南

  • 🛠️

    优先原生，依赖可控

    优先使用 .NET 原生能力，能不引第三方就不引；引入的每个依赖都在框架概述里列明版本与用途，依赖面始终看得见。

    了解设计理念

    有完整的实战参考
