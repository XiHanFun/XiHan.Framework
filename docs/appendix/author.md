## 开源初衷

写框架的起点很朴素：我自己的几个应用需要一份共用的后端基座，与其在每个项目里复制一遍，不如把它做成一个可以长期维护的东西。既然要长期维护，就干脆按十年的尺度去设计它；既然已经设计好了，公开出来让更多人用、让更多人挑毛病，只会让它更好。曦寒懿生态里的开发框架、视图组件、基础应用和四款设计器都是这个想法的延伸。

开源版本采用 MIT 协议，核心能力永久免费，个人和企业都可以使用与商用。已经以 MIT 公开的能力不会再改成收费。

## 兴趣

对新技术保持好奇，钟情于开源，乐于把踩过的坑写成文档。技术之外，崇尚自然与人文，追求精神上的自由，喜欢汉服与古风文化。

## 技术

最熟悉的语言是 C# 与 TypeScript，长期在 .NET 与前端两侧工作。XiHan Framework 用的 .NET，XiHan.UI 用的 TypeScript，二者分别是生态的后端与前端基座。在框架之外，我对软件工程、架构设计、底层原理与跨语言互操作始终抱有热情，这也是为什么 XiHan Framework 5 从一份语言中立的规范开始。

## 常用工具

Visual Studio、JetBrains Rider、Visual Studio Code、PostgreSQL、Docker，以及各种 AI 编码助手。框架为这些助手准备了离线知识库与提示词，见 [AI 辅助开发](/agents/agents)。
