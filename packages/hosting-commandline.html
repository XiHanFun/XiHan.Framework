XiHan.Framework.Hosting.CommandLine ​

命令行宿主：在 .NET 通用宿主里把命令行参数翻译成内核调用，内置 help、graph、pipeline、operations、invoke 命令。适用于运维工具、批处理脚本，以及要以 stdio 给 MCP 客户端当子进程的应用。

项内容
包 IDXiHan.Framework.Hosting.CommandLine
环层Ring 4（宿主）
能力—
特性入口—（AddXiHanCommandLine() 登记）
配置节—；环境变量 XIHAN_CONFIG_PATH（挂载的配置目录）、XIHAN_AUTHORIZATION（缺省凭据）
依赖XiHan.Framework.Kernel、XiHan.Framework.Security.Abstractions、XiHan.Framework.Localization.Abstractions；Microsoft.Extensions.Hosting、Microsoft.Extensions.Configuration.Json、Microsoft.Extensions.Logging.Console
AOT兼容（IsAotCompatible）
稳定性Preview

概述 ​

一次进程执行一条命令。invoke <操作 ID> 与简写 <resource> <verb> 把 --json、--data 或字段选项拼成载荷，把 --tenant、--correlation、--locale、--timeout、--authorization 翻译成调用上下文，经完整内核管道调用暴露给命令行（Expose.CommandLine）的操作。成功时响应 JSON 写到 stdout，失败时一行 {"code","detail","traceId"} 写到 stderr，退出码按错误码的 KIND 段决定。AddXiHanCommandLine() 把日志改成只写 stderr，stdout 只有命令输出。

其他包可以登记自己的命令：实现 ICommand 后 AddXiHanCommand<T>()，Protocols.Mcp 就以这种方式提供 mcp 命令（MCP 的 stdio 传输）。

何时使用 ​

同一份操作契约要在终端、CI 脚本或定时任务里调用时用它；要让 MCP 客户端以子进程方式连接应用时，与 Protocols.Mcp 一起用。对外提供网络服务用 Hosting.AspNetCore。组合包都不包含本包。

安装与启用 ​

bash
dotnet add package XiHan.Framework.Hosting.CommandLine --prerelease

当前是预览版，安装要带 --prerelease；从源码或本地包源引用见快速上手。

csharp
using Microsoft.Extensions.Hosting;
using XiHan.Framework.Hosting.CommandLine;
using XiHan.Framework.Profiles.Minimal;

var builder = Host.CreateApplicationBuilder(args);
builder.AddXiHan(xihan => xihan.UseMinimalProfile());
builder.Services.AddXiHanCommandLine();

return await builder.Build().RunXiHanCommandLineAsync(args);

使用示例 ​

bash
dotnet run --project framework/samples/SimpleCli -- greetings create --name Ada --times 2
dotnet run --project framework/samples/SimpleCli -- invoke greetings.create --json '{"name":"Ada"}' --locale zh-CN
XIHAN_AUTHORIZATION="ApiKey dev-alice-key" dotnet run --project framework/samples/SimpleCli -- greetings create --name Ada

自定义命令与选项的完整说明见命令行宿主。

行为与限制 ​

  • 解析：第一个非选项记号是命令名；--name value、--name=value、无值的 --flag 记为 true；-- 之后全是位置参数；载荷按 --json（须为对象）> --data <file>（可写 @file）> 字段选项的顺序取，字段选项重复时成数组。
  • 字段选项按操作的请求 Schema 写成对应类型（布尔、整数、浮点、数组），转换不了的值留字符串，由 Validate 阶段报 KERNEL_VALIDATION_003；--json 与 --data 的载荷原样进入。操作没有 Schema 时值都是字符串，请求类型要从字符串读数字，序列化上下文需要 NumberHandling = JsonNumberHandling.AllowReadingFromString。
  • 保留选项 json、data、authorization、tenant、correlation、locale、timeout、help 不进载荷。
  • --authorization 与 XIHAN_AUTHORIZATION 只作用于 invoke；mcp 命令的调用以匿名主体执行。
  • 命令名重复时 CommandLineRunner 构造失败（ArgumentException）。
