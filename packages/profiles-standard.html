XiHan.Framework.Profiles.Standard ​

Standard 组合包（元包）：Minimal 加 Domain 与持久化、缓存、多租户、安全、消息五个子系统的抽象与内存默认实现，UseStandardProfile() 装配它们。大多数业务服务从这里开始，零外部基础设施即可运行。

项内容
包 IDXiHan.Framework.Profiles.Standard
环层Ring 6（组合包）
能力自身不声明；装配的默认实现提供的能力见下文
特性入口UseStandardProfile()
配置节—
依赖XiHan.Framework.Profiles.Minimal、XiHan.Framework.Domain，以及 Persistence、Caching、MultiTenancy、Security、Messaging 各自的 .Abstractions 与 .InMemory
AOT兼容
稳定性Stable

概述 ​

UseStandardProfile() 先调用 UseMinimalProfile()，再装配五个内存默认实现：

特性包提供的能力
InMemoryLocalizationFeature（来自 Minimal）Localization.InMemorylocalization.resources@1
InMemoryPersistenceFeaturePersistence.InMemorypersistence.relational@1
InMemoryCachingFeatureCaching.InMemorycaching.local@1、caching.distributed@1
InMemoryMultiTenancyFeatureMultiTenancy.InMemorymultitenancy.context@1、multitenancy.sharding@1
InMemorySecurityFeatureSecurity.InMemorysecurity.authentication@1、security.authorization@1
InMemoryMessagingFeatureMessaging.InMemorymessaging.queue@1

它们都是清单里的 role: default。再 UseFeature 一个声明同一能力的显式 Provider（EntityFrameworkCorePersistenceFeature<TContext>、RedisCachingFeature、JwtSecurityFeature、RabbitMQMessagingFeature 等），能力求解就选中 Provider。默认实现提供的能力全部被顶替时不装配、不启动；还有能力被选中时照常装配，只为被选中的能力注册服务，例如加入 RedisCachingFeature 后 Caching.InMemory 仍提供 caching.local，加入 JwtSecurityFeature 后 Security.InMemory 仍提供授权（RFC-0002，能力包与清单）。换 Provider 只加包引用、UseFeature 与配置，业务代码不变。

这些特性填满管道的中段：Authenticate（ApiKey）→ Tenant（声明或 Baggage）→ Authorize（策略与权限）→ Idempotency（幂等键）→ Transaction（工作单元）。本地化不占阶段：宿主在 Ingress 把 Accept-Language 协商进 Baggage xihan.locale，在 Egress 把失败结果翻译成 Problem Details 的 detail。

何时使用 ​

  • 业务服务，需要仓储、缓存、租户、鉴权与消息，开发与测试阶段不想起外部服务：用 Standard。
  • 还需要对象存储、调度、审计、工作流、OpenTelemetry 与四种协议适配器：用 Profiles.Full。
  • 只要内核与宿主：用 Profiles.Minimal。

安装与启用 ​

bash
dotnet add package XiHan.Framework.Profiles.Standard --prerelease

当前是预览版，安装要带 --prerelease；从源码或本地包源引用见快速上手。

csharp
using XiHan.Framework.Hosting.AspNetCore;
using XiHan.Framework.Messaging.Abstractions.Outbox;
using XiHan.Framework.Profiles.Standard;
using XiHan.Framework.Protocols.Http;
using XiHan.Framework.Protocols.Http.Routing;

var builder = WebApplication.CreateBuilder(args);

builder.AddXiHan(xihan => xihan
    .UseStandardProfile()
    .UseFeature<HttpProtocolFeature>()
    // 可选：事务性发件箱
    .UseFeature<OutboxFeature>());

var app = builder.Build();
app.UseXiHan();
app.MapXiHanHealth();
app.MapXiHanOperations();
app.Run();

samples/SimpleApp 是完整示例：Standard 组合加 HTTP、MCP、gRPC、CloudEvents 协议适配器与两个业务能力包，也是 Native AOT 冒烟示例。

主要类型 ​

类型说明
StandardProfile静态类，扩展方法 UseStandardProfile(this AppBuilder)

行为与限制 ​

  • 内存默认实现都有容量上限，进程重启即丢数据，适合开发、测试与单进程场景；上线前按需换 Provider，各默认实现的容量与语义见其包页。
  • Security.InMemory 从配置装载 ApiKey 主体与授予，配置里的密钥只用开发值。
  • 宿主在 Ingress 把 Accept-Language 协商进 Baggage xihan.locale，在 Egress 用 IMessageLocalizer 把失败结果翻译成 Problem Details 的 detail，缺省英文，内置 10 种语言（RFC-0010）。
  • 组合包不读配置，也不改任何默认值；各特性的配置节照常生效。
