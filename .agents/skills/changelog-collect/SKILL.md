# XiHan.Framework 变更日志整理

## 事实源

- 用户指定的起止 tag/commit；未指定时先列出最近正式 tag 和当前 HEAD。
- 对应范围的提交、实际 diff、合入 PR、公共 API 与包变化。
- `docs/changelog.md` 当前“新增 / 修复 / 优化 / 调整 / 升级 / 移除”格式。

## 收录规则

- 只收录 NuGet 消费者可感知的能力、修复、默认行为、性能、安全、配置和兼容性变化。
- 纯测试、CI、内部重构和构建脚本不单独收录，除非改变包产物或使用方式。
- 每条以使用者结果表达，写明模块、包、API 或配置名，不罗列内部文件。
- 破坏性 API、配置键、缓存/消息键、数据布局、序列化和默认实现变化放入升级须知，给出迁移步骤。
- 跨多个模块的同一底层修复合并描述；只有不同用户影响才拆分。
- 依赖升级仅在带来可感知行为、安全或兼容性变化时说明。

开发阶段先维护 `## 未发布`；正式版本形成 `## vX.Y.Z (YYYY-MM-DD)`。版本脚本可以提供提交范围线索，但本技能不运行 VersionUpgrade、不改 `version.props`、不构建和不发布。
