# XiHan.Framework 资源治理

开始前读 `references/defaults-and-resources.md`，并检查目标契约、默认实现、Provider 与并发测试。

## 不可变约束

- 框架默认实现使用 `DefaultXxx`，零外部基础设施依赖且容量有界。
- Redis、数据库、消息队列和云 Provider 由消费应用选择；Framework 只定义稳定契约和必要扩展点。
- 集合、缓存、队列和历史记录必须明确容量、过期、驱逐、清理与关闭语义。
- 外部服务不可用时，只有契约明确允许才可降级；否则快速且可诊断地失败。
- 不添加无限重试、无界内存集合或伪装成跨进程一致性的内存实现。
- 后台任务、计时器、订阅和连接必须响应取消并在关闭时释放。

## 验证

测试空状态、上限、过期、驱逐、重复写入、并发、取消和释放。诊断内存事件时区分宿主 OOM、应用无界增长和正常长连接，只根据日志、指标、转储和代码路径下结论。
